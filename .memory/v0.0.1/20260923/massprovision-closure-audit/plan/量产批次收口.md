## 判据纪律（本计划遵守）

1. 凡"靠配置生效"的改动，必须**真跑一次**证明它会响（门禁本身要有负控）——本轮两次照做（预设生效、符号门禁负控）。
2. 门禁必须**整仓跑**，只跑改动包会漏掉接口变更引发的编译回归（本轮 C 项的成因）。
3. 证据分档：真机/真构建/真库 > 单测 > 读代码；文档里逐项标注档位，不混算。
