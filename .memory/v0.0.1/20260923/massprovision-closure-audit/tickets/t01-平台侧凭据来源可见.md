# t01 平台侧"凭据来源可见"（P0-A 服务端半边）

**状态**：✅ 已完成（backend）
**问题**：SDK 把"把在线设备里 `esp.cred_source != "partition"` 的标出来"写成**必需，属 backend 侧**，
但当时只有设备侧上报，云端无消费者 —— 键只是躺在影子文档里，**看不见、不告警**。

**实现**
- 新包 `src/rmneo/credsource`（判决，无 IO）：`Classify()` 三态（`partition`/`embedded`/`unknown`）+
  `Fingerprints`（部署侧登记 `DEVICE_COMMON_CERT_FINGERPRINTS`，键缺失时按台账 `GetByNodeID` 兜底）+
  `ChangeTracker`（按取值变化去抖）。
- 接线 `src/rmneo/shadow/cmd/shadowd/cred_identity.go` + `main.go` 上报回调：
  `embedded` ⇒ `logWarn` + 一条 `messaging.EventDeviceAlarm`（critical，含 `remedy`）+ gauge
  `shadowd_device_identity_embedded`；`partition` ⇒ 首见/恢复时 INFO；取值不认识 ⇒ WARN（**不**升级为设备告警）；
  **键缺失不喊**。
- 归属空间/租户只解析一次（`routeReportEvents` 改签名接收 `spaceID/tenantID`，避免每台上报两次查询）。

**验证**：`go test ./src/rmneo/credsource/... ./src/rmneo/shadow/cmd/shadowd/...` 全绿；
用例覆盖：只在变化时告警、**恢复后再次回退要再喊**、键缺失静默、未知取值只 WARN、
指纹兜底 `basis=fingerprint` 与设备自报可区分、**空指纹清单 ⇒ 兜底完全不参与**。

**边界**：`esp.cred_source` 是影子 `reported` 的普通键（非 topic/能力位）⇒ 不改契约面；
指纹兜底默认关闭；台账查询每台只做一次（已 probe 缓存）。
