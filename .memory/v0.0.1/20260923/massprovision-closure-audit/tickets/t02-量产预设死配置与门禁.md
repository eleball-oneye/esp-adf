# t02 量产预设：死配置 + 端点未钉死 + 新增可复跑门禁

**状态**：✅ 已完成（esp-adf）

**问题**
1. `sdkconfig.defaults.production` 写的 `CONFIG_ONEYE_FW_TRANSPORT_MQTT_TLS=y` **在本工程不存在**
   （真名 `CONFIG_ONEYE_FW_TRANSPORT_TLS`）⇒ "显式钉住承载"是安慰剂；§8.7.3 的"预设真生效"证据清单
   里**恰好没检查这一项**。
2. 预设没钉 `CONFIG_ONEYE_FW_CLOUD_HOST/_PORT`（另一半静默失败轴 = 掉回占位地址 `192.168.1.100:0`）。

**实现**
- 改对符号名；补钉 `mqtt.oneye.me` / `18885`，并在文件头写明"本文件每一项都必须能被验证"。
- 新增 `tools/check-sdkconfig-defaults.py`：符号全集 = Kconfig 扫描 ∪ 本地/指定 `sdkconfig`；
  报出 defaults 里**不存在**的符号（`CONFIG_X=v` 与 `# CONFIG_X is not set` 两种写法都查）；
  `--sdkconfig` + `--require` 时**逐项对照生成值**（"未生效"也报）；无 `IDF_PATH` 时打印误报提示。

**验证（全部真跑）**
| 项 | 结果 |
| --- | --- |
| 量产预设真构建（WSL + IDF 5.5.5，独立 `-DSDKCONFIG`） | `BUILD_EXIT=0`，`korvo2_oneye.bin = 0xf08f0`，`0x10f710 bytes (53%) free` |
| 预设逐项生效 | `--sdkconfig <产物>/sdkconfig --require sdkconfig.defaults.production` ⇒ **11 项全部存在且已生效**（含 `TRANSPORT_TLS=y`、`CLOUD_HOST="mqtt.oneye.me"`、`CLOUD_PORT=18885`） |
| 开发用 `sdkconfig` 未被污染 | SHA-256 前后一致 `A067A382…88CD` |
| 红线守卫 A/B（复验） | A（`REQUIRED=y` + `main/certs` 存在）⇒ `idf.py` **exit 2** + 两条修法；B ⇒ exit 0 |
| 门禁负控 | 把 `_MQTT_TLS` 与拼错的 `# … _WIFI_FILES is not set` 塞回 ⇒ **exit 1** 并逐行点名 |

**踩过的坑（写脚本时）**：① WSL 里必须 `export ADF_PATH`，否则报的是
`/CMakeLists.txt` 不存在 + `Failed to resolve component 'oneye-dev-sdk'`（看起来像组件丢了）；
② 必须**清掉旧构建目录**再配，否则 CMakeCache 会把上一轮的 `-DONEYE_FW_CERT_DIR` 留在缓存里，
表现为"我传了空证书目录却仍然嵌入了证书"。
