## 仍未拍板

**设备私钥在哪生成**（设计 §8.6 #1 / §8.8.1）：指**设备私钥 `client.key`**（一机一密 mTLS 用），
不是平台 CA 私钥。两条路都已支持：
- A 服务端生成（**当前缺省**）：ZIP 带 `client.key`；代价 = 私钥在服务端内存/临时件/归档里出现；
- B 产线生成只递 CSR（含 B′ `mkcreds -assemble` 本地组装）：私钥不出产线；代价 = 产线多一个工具，
  且**丢密钥必须重签**（A 路还能从归档补发）。
- **建议**：产线既然已联网+控制台操作，B 的边际成本只是一个密钥生成步骤，换"服务端与备份不再
  是私钥泄露面"；若产线暂时不方便加工具，可先用 A 上量、B 作为下一轮目标（接口无需再改）。
