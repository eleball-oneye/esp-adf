## 踩过的坑（留给后来人）

1. **`go run … &` 杀不干净**：`go run` fork 出真服务进程，杀父进程留下孤儿 ⇒ 端口被旧实例占着，
   新一次验收打在上一个实例的内存台账上，现象是"新签的 SN 居然 already_issued"。
   改成 `go build -o … && ./bin &`，并在起服务前**探测端口是否已有服务**（有就直接停）。
2. **git-bash（MSYS2）会改写以 `/` 开头的参数**：`openssl req -subj "/CN=…"` 变成 `C:/Program Files/Git/CN=…`。
   改用 `-config` 配置文件，Linux 与 git-bash 行为一致。
3. **申领服务读 CA 是只读的**（`ca.LoadFile`，与 shadowd 的 `LoadOrCreateFile` 不同）⇒ 本机验收要先自己铸 CA。
4. **i18n 门禁要字面键**：`t(row.status)` 这类动态键无法被静态核对 ⇒ 状态显示名用字面映射（三个取值都写出来）。
