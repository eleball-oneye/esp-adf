## 实现

- **令牌台账**：`src/rmneo/auth/tokenguard`（内存 + PG `access_tokens`）+ `guardbuild`（`SHADOW_STORE_MEM=1` ⇒ 内存仅 dev / `PG_DSN` ⇒ 两服务共享）；所有令牌带 `jti`；登录与续期**记一行**，记不进就不发；消费侧验签后查台账，读不出来 ⇒ **fail-closed**。
- **控制面四条路由**（admin-only）：`GET /v1/auth/tokens`、`POST /v1/auth/tokens/{jti}/revoke`、`POST /v1/auth/subjects/{subject}/revoke`、`POST /v1/auth/tokens/renew`（旧令牌不自动吊销）；未知 jti ⇒ 404。
- **身份视图**：`GET /v1/devices/cred-identity[?identity=]`（来自上报路径的最近判决；未装配 ⇒ 503）。
- **控制台两页**：`/home/user-management/access-tokens`（列出/吊销/按主体吊销/续期并写回本地存储）、`/home/node-management/cred-identity`（统计卡 + 逐台表 + Badge + 处置建议）。
- **登录收敛**：`authenticate()` 在 `ADMIN_LOGIN_ONLY` 下只认环境变量那对固定凭据；用户表分支仅在 `=0` 时可达（既有 `users_test` 显式开旧口径，新增用例钉住缺省收紧）。
